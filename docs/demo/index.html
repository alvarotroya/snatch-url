Snatch URL, the second address bar

The popup above is the extension's real popup.html, popup.js and styles.css, loaded from the repository root and given a fake tab to work on. Click a part of the URL to type over it, click a section cell to open its drawer, try ⚡ Clean on the monster URL, and press Apply: the mock address bar above follows, and the log below records what the extension asked the browser to do.

What happened

    What this demo cannot show

    • The real popup closes when it loses focus and reopens fresh from the toolbar icon; reopen popup stands in for that.
    • Chrome sizes the real popup from its content and caps it at 800 × 600; the frame here mimics that cap but is not the browser's own bubble, and Firefox's panel is not simulated. On a phone the frame takes the screen's width, as Firefox for Android's popup does, and keeps the 600 cap, which that popup does not have.
    • Restricted pages (chrome://, the Web Store, about:) fail in the real popup with a "Can't edit this page" message; the fake tab never refuses.
    • Clipboard access runs under this page's permissions, not the extension's.
    • Navigation is simulated: nothing is loaded, only the mock address bar changes.

    Running it

    Serve the repository root over HTTP (python3 -m http.server 8000) and open /docs/demo/. A file:// open does not work: the popup is an ES module, which browsers refuse to load from disk.
